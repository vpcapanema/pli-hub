# Análise Estratégica do Portfólio

## Objetivo
Realizar uma análise completa de todas as aplicações antes de definir qualquer estratégia comercial.

## Princípios
- Não assumir que cada aplicação será um produto.
- Primeiro compreender todas as aplicações.
- Somente após a análise completa definir produtos, módulos, componentes e serviços compartilhados.

## Estado atual
### Concluído
- Criação do PLI Hub.
- Identificação das 13 aplicações cadastradas.
- Classificação preliminar por categorias existentes.
- Definição da metodologia de análise.

### Pendente
Para cada aplicação:
1. Explorar toda a interface.
2. Mapear funcionalidades.
3. Identificar arquitetura funcional.
4. Avaliar maturidade.
5. Avaliar dependências.
6. Identificar sobreposição com outras aplicações.
7. Determinar se é:
   - Produto
   - Módulo
   - Serviço compartilhado
   - Biblioteca
   - Ferramenta interna
   - Protótipo

## Entregáveis finais
- Arquitetura da empresa.
- Catálogo de produtos.
- Plataforma comum.
- Serviços compartilhados.
- Roadmap de evolução.
- Estratégia comercial.
- Priorização de desenvolvimento.

## Regra principal
Nenhuma decisão comercial deve ser tomada antes da conclusão da análise de todas as aplicações.
